# Metal Arm MoveIt

This directory contains ROS Noetic MoveIt configuration packages for the MakerMods Metal arm.

## Dependencies

- Ubuntu 20.04 LTS
- ROS Noetic
- MoveIt for ROS 1

Install MoveIt from ROS packages:

```bash
sudo apt update
sudo apt install ros-noetic-moveit
```

## Build

Build the workspace from the ROS 1 workspace root:

```bash
cd ~/metal_ros
bash build.sh
source devel/setup.bash
```

## Real-Arm Control

Start the Metal arm controller first:

```bash
roslaunch metal_controller single_arm_control.launch
```

Then start one of the MoveIt configurations.

Without gripper:

```bash
roslaunch metal_no_gripper_moveit demo.launch
```

With gripper:

```bash
roslaunch metal_with_gripper_moveit demo.launch
```

In RViz, use the end-effector marker to choose a target pose, then use the MotionPlanning panel to plan and execute.

## Notes

- Package names such as `metal_no_gripper_moveit` and `metal_with_gripper_moveit` are retained for compatibility.
- The no-gripper configuration controls joints `joint1` through `joint6`.
- The gripper configuration adds the gripper joints and planning groups generated by MoveIt Setup Assistant.
